# Security policy

NODO handles private meetings and documents, so security reports are taken seriously.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting instead:
**Security tab, then "Report a vulnerability"** on this repository.

Include what you found, how to reproduce it and which version or commit you tested. You should get a
first reply within a few days.

## Scope

In scope: the local engine, the loopback HTTP API, the read-only MCP server, model download and
verification, backup and restore, and the Azure infrastructure code.

The security model is described in the [README](README.md#security-and-privacy-model).
